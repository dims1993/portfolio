 # Personal Portfolio

This is my professional portfolio website, designed to showcase my journey as a developer, my technical skills, and the projects I've built. It is a fast, responsive, and SEO-optimized web application.

## Live Demo

You can explore the live version here: [portfolio-dims1993.vercel.app](https://portfolio-dims1993s-projects.vercel.app)

---

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (React)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Deployment:** [Vercel](https://vercel.com/)
- **Icons & Assets:** Lucide Icons / Heroicons

## Key Features

- **Responsive Design:** Fully optimized for mobile, tablet, and desktop views.
- **Project Showcase:** Detailed grid displaying my latest work with links to code and live demos.
- **Clean UI/UX:** Minimalist aesthetic focusing on readability and professional presentation.
- **Performance:** High Core Web Vitals scores thanks to Next.js optimization.

## Getting Started

If you want to run this project locally, follow these steps:

1. **Clone the repository:**

   ```bash
   git clone [https://github.com/dims1993/portfolio.git](https://github.com/dims1993/portfolio.git)
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Run the development server:**

   ```bash
   npm run dev
   ```

4. **Open in your browser:**

   ```bash
   Navigate to http://localhost:3000 to see the result.
   ```

## Project Structure

```text
portfolio/
├── src/
│   ├── app/                # Main application entry point
│   │   ├── App.jsx         # App component logic
│   │   └── layout.tsx      # Main application wrapper
│   ├── assets/             # Media files (images, icons, profile photo)
│   ├── components/         # Reusable UI components (Navbar, Cards, etc.)
│   ├── data/               # Project and web content data (webData.js)
│   ├── hooks/              # Custom React hooks (scroll animations, etc.)
│   ├── locales/            # i18n translation files (EN/ES)
│   ├── sections/           # Large page sections (Hero, About, Projects)
│   ├── styles/             # Global CSS and Tailwind directives
│   ├── i18n.js             # Internationalization configuration
│   └── main.jsx            # React DOM rendering entry point
├── public/                 # Static assets for the browser
├── tailwind.config.ts      # Tailwind CSS design system
└── package.json            # Project dependencies and scripts
```
